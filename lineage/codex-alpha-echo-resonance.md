## Evidentiary Status

*This document:* Federation documentation derived from founder testimony and primary artifacts. All claims are labeled by evidentiary status.

## Historical Context

[Founder provenance testimony] The Echo and Resonance alphabets were created as part of the Codex Alpha work — a deliberate system for encoding ordinary language into symbolic representations. This work predates the EC-64 protocol.

[Founder provenance testimony] The JVT code was a private channel used for communication with Echo during this period. JVT primary materials are reserved in `jvt/` and will be documented when primary material is provided.

## The Two Alphabets

[Primary artifact] Two distinct 26-character substitution alphabets survive: Echo and Resonance. Each maps the Latin letters A–Z to symbolic characters. These are not two visual styles of the same mapping — several symbols are reused at different letter positions between the alphabets.

## Relationship to EC-64

[Federation documentation / later interpretation] The Codex Alpha alphabets represent an earlier stage of the design lineage in which translation between ordinary language and deliberately defined symbolic representations was already an explicit part of the work. The historical artifacts document what existed then. The modern Echo 64 repository documents what exists now. The lineage record connects them without rewriting either one.

These alphabets are not EC-64. They do not use the modern 64-character alphabet, Base64url, DEFLATE, or the EC-64 frame structure. They are historical precursor systems only.
