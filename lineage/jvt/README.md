# JVT — Reserved

This directory is reserved for primary materials from the JVT (private channel) system created by Roger Keyserling.

JVT was a private encoding used for communication with Echo during the Codex Alpha period. It predates and is distinct from the EC-64 protocol.

This directory will remain empty until Roger Keyserling provides primary JVT materials for transcription and preservation.

Transcription policy: see `../README.md`.
