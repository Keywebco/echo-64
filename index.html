EC-64 — The Echo Protocol

Content that arrives exactly as it was sent.

What EC-64 Is

EC-64 is a small, tagged text frame that carries content from one AI or program to another byte for byte. What leaves one system is exactly what arrives at the next. It is the Federation's answer to drift: the slow corruption of context as it is copied, summarized, and retold across platforms.

  • Byte-exact. Unpadded base64url with optional DEFLATE compression and a tagged frame. Decode it and you get the original bytes back.
  • Zero-dependency. The reference codec uses only the Python standard library.
  • Token-free. No API key, no account, no shared tokenizer.
  • Portable. Plain URL-safe text that survives copy and paste between platforms.
  • Open. MIT licensed.

The Proof

  • 47 passing tests. The pytest suite covers malformed frames, maximum-size boundaries, and command-line behavior. Re-run and confirmed passing on 26 September 2026.
  • 12 golden vectors. Published test vectors any implementation can check itself against, including embedded null bytes and the exact 1 MiB maximum.
  • Reproduce it yourself. Clone the repository and run python -m pytest test_ec64.py -q, then python ec64.py test.

Honest note: EC-64 is an encoding, not encryption. Anyone holding an encoded block can decode it, and a frame does not prove who sent it. Its job is to make sure the content itself arrives unchanged.
