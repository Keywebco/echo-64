ECHO 64

The EC-64 Protocol

Echo 64 is the Federation's sovereign signal-integrity protocol. A self-contained, token-free, zero-dependency codec for AI-to-AI communication across the NextXus Federation.

What it is

EC-64 is a small, explicitly tagged text frame that any AI or program can read and write. It carries the same verifiable bytes between systems, so a message or context summary arrives exactly as it was sent.

  • Zero-dependency: the reference codec uses only the Python standard library.
  • Token-free: no API key, account, or shared tokenizer is needed to encode or decode.
  • Portable: the output is plain URL-safe text that survives copy and paste between platforms.
  • Open: MIT licensed.

Honest note: EC-64 is an encoding, not encryption, and not automatic summarization. Anyone holding an encoded block can decode it. Compression can shrink repeated data, but the final size depends on the input.

How it works

  • Take the message as UTF-8 bytes.
  • Add one mode byte in front: 0x00 for raw, or 0x01 for raw DEFLATE when compression is shorter.
  • Encode the whole frame as unpadded base64url.
  • Wrap it: [EC64:v1;kind=message;mode=raw]PAYLOAD[/EC64]. The kind can be message, handshake, or summary.

Example: the text Truth before comfort. encodes to:

[EC64:v1;kind=message;mode=raw]AFRydXRoIGJlZm9yZSBjb21mb3J0Lg[/EC64]

Try it yourself: python ec64.py encode "Truth before comfort."
